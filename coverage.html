Notes for developers
HierarchyLoudest to quietest: live tracks, own vehicles, gaps, coverage geometry. Coverage detail (class rings, drone rings, acoustic) renders only for the selected vehicle.
ColorsBlue = own assets. Red = tracks and unacknowledged alerts. Amber = warnings only (stale, battery, link). Coverage is a neutral tint. Gap is a distinct orange so it never reads as a threat.
BasemapMockup uses Leaflet with a dark or satellite tile layer. Production caches tiles for base mode (no uplink). Overlay here is one SVG on geographic bounds; production draws in lat/lon with MapLibre + deck.gl.
Ontology graphMaintained in memory in this mockup as typed nodes and typed edges (see the graph dump below). Node types: Site, Zone, Asset, Vehicle, PTZ, AcousticArray, Dock, Drone, Operator, Track, Gap, Task. Relations: mounted_on, docked_at, operates, assigned_to, part_of, observes, dispatched_to, tasked_to, targets, closes, within. The Relations panel and the "Cover asset" target resolution read from the graph; tasks add and remove edges as they progress. Production: PostgreSQL tables for nodes and edges with PostGIS geometry on spatial nodes; no graph DB needed until the fleet is large.
InputsPer vehicle over LoRa every 10–30 s: position, heading, PTZ pan/tilt/zoom, drone state, battery, link quality, sensor health. Show "last heard" per vehicle; go amber past 60 s, red past 180 s.
PTZ reachableRadii from the calibrated confidence-gate range per class (person, vehicle, plate), not spec sheet. Default disk = person range.
Terrain shadowViewshed from DEM at sensor height, subtracted from the disk. Server-side, cached per position.
Drone reachTime-to-arrive rings bounded by link, legal range, geofences. Dashed unless docked and ready.
GapSite minus union of coverage, per capability. SVG mask here; PostGIS ST_Difference(ST_Union) in production, every 10 s.
SelectionSelecting a node highlights its relations. Edges drawn only for live relations (dispatched_to, tracking). Never draw the whole graph on the map.
TaskingStructured tasks only, no free text: move_to, cover_asset, aim_ptz, launch_recon, recall, hold, return. Each ~30–60 bytes CBOR: task_id, vehicle, type, target, priority, expiry, signature. Fits one LoRa packet at SF7–SF9.
DeliveryStates: sent → delivered (vehicle ACK) → awaiting confirm (driver hears it) → accepted/rejected → underway → done. Retry on no ACK with the same task_id; vehicle dedupes. Expired tasks never execute. Every transition is logged to the event feed.
Human in loopAny task that moves the vehicle or launches a drone needs the driver's voice confirm. PTZ re-aim executes automatically and is announced. Same rule as the drone workflows.
PreviewDragging the ghost recomputes coverage and gaps client-side (here: the ghost disk joins the gap mask). Production runs the same PostGIS query with the proposed position.
SecurityPer-vehicle key; task_id signed. Tasks and ACKs get airtime priority over routine SITREPs.
